# Real Estate Project 🏠

A web platform for **buying, selling, and renting properties**.  
Built with **PHP** (backend) and **MySQL** (database).

## Features
- User authentication (Login/Signup)
- Buy, Sell, Rent properties
- Property categories: Flats, Plots, Bungalows, Houses, Rooms
- Document verification
- Commercial & Non-commercial property support

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP  
- **Database**: MySQL
